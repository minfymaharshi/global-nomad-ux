| 2026-09-03 14:20 IST | `Global_Nomad_UX.html` | The disaster wizard's height-pinning worked on desktop and silently didn't on phone. The phone frame renders inside a scaled ancestor (`.zoom`, so a 412px device fits the pane); `getBoundingClientRect()` returns a height already multiplied by that scale, and writing that same number as a CSS `min-height` gets it multiplied by the scale a second time on render — so the pinned frame came out smaller than either step's real content, and the panel still visibly resized moving between steps. Only found by measuring on the phone surface directly; desktop, with no ancestor transform, looked correct the whole time it was actually wrong.
